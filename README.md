# SriKumaran VM - Portfolio

Modern, animated portfolio website showcasing projects and skills in Data Science and AI Engineering.

## 🚀 Quick Start

### Option 1: One-Click Launch (Recommended)
Double-click **`start-portfolio.bat`** - This will:
- Start the local server automatically
- Open your portfolio in the default browser
- Keep running until you press Ctrl+C

### Option 2: Open Existing Server
If the server is already running, double-click **`open-portfolio.bat`** or **`OPEN_ME.html`**

### Option 3: Direct File Access
Double-click **`index.html`** to open directly (some features may not work without a server)

### Option 4: Manual Command Line
```bash
npx http-server -p 8080 -o
```
